# Enterprise Software — Competitive Feature Inventory

> Advertised capabilities of the category-leading incumbents, scraped from their public product / features / pricing pages (with G2/Gartner/analyst fallbacks where vendor pages blocked). Purpose: the master capability map the platform's blueprints/planner must be able to generate.

### Email/Marketing — common feature themes
- **Drag-drop email builders are table stakes** — no-code block/WYSIWYG editor + large responsive-template library + brand-kit governance + mobile/inbox-rendering testing. Depth differentiates: AMPscript/Liquid scripting (Salesforce, Braze), reusable modular Content Blocks with API (Braze), Content Studio DAM (Mailchimp).
- **Visual journey/automation builders are the core engine** — canvas with triggers, conditional/decision splits, delays, pre-built templates (welcome/abandoned-cart/post-purchase/win-back). Braze/Salesforce add API-triggered and transactional real-time journeys.
- **Segmentation + predictive/behavioral targeting universal**, tiered by data model — SMB tools (Constant Contact, Mailchimp) rule-based; leaders offer real-time behavioral over full event history (Klaviyo), SQL/zero-copy warehouse segments (Braze CDI, Salesforce Data Cloud), predictive segments (churn/CLV/next-order).
- **AI is the primary battleground** — Intuit Assist, Klaviyo AI (40+), BrazeAI + agentic Decisioning Studio, Adobe Sensei/GenAI, Einstein + Agentforce, Breeze Copilot/Agents, BrandKit AI. Recurring: generative copy/subject lines, send-time optimization, predictive scoring, and — newest — autonomous/agentic assistants.
- **A/B + send-time optimization everywhere**; multivariate + AI "best-variant-per-recipient" (Klaviyo, Braze Intelligent Selection, Einstein) are up-market differentiators.
- **Omnichannel beyond email now standard** — SMS/MMS near-universal (add-on for SMB tools); mobile push + in-app + WhatsApp separate the true engagement platforms (Braze/Klaviyo/Salesforce/Marketo/HubSpot) from email-first SMB tools (Mailchimp/Constant Contact). Braze widest (push/web push/Content Cards/RCS/LINE/KakaoTalk); paid-media/ad-audience sync common.
- **Landing pages, forms, pop-ups bundled everywhere**; progressive-profiling/multi-step forms + CloudPages/microsites are the enterprise/B2B upgrade (Marketo, Salesforce).
- **Deliverability tooling shared pillar** — dedicated IPs, SPF/DKIM/DMARC, IP warming, reputation monitoring, seed/inbox-placement testing. Klaviyo (Deliverability Hub) + Braze surface it as a named product; enterprise adds bot-filtering (Einstein Metrics Guard).
- **CDP/first-party-data story is the strategic dividing line** — Klaviyo (KDP), Braze (Data Platform + Cloud Data Ingestion/Currents), Salesforce (Data Cloud) position a unified-profile CDP vs the lighter contact-database model of Mailchimp/Constant Contact. HubSpot's Smart CRM is the built-in-CRM variant.
- **Analytics ranges from campaign metrics to full revenue attribution** — enterprise/B2B add multi-touch attribution + revenue-cycle analytics (Marketo Measure/Bizible, Salesforce Datorama, HubSpot), plus peer benchmarking (Klaviyo, Mailchimp).
- **B2B vs B2C/e-commerce is the clearest positioning split** — Marketo + Pardot center on lead scoring/grading/nurturing/ABM/CRM sync; Klaviyo/Mailchimp/Constant Contact center on e-commerce (Shopify/WooCommerce sync, product recommendations, abandoned-cart, shoppable emails). HubSpot straddles both via its unified CRM.
- **Large integration marketplaces + open APIs universal** (300+ Mailchimp, 350+ Klaviyo, 170+ Braze, 2,000+ HubSpot, AppExchange/LaunchPoint for Salesforce/Marketo). Emerging differentiator: MCP servers for LLM/agent access (Klaviyo, Braze).
- **Adjacent SMB bundles differentiate** — Constant Contact (events/RSVP, website + logo builder, surveys) + Mailchimp (websites, transactional email via Mandrill, Content Studio) bundle broad SMB tooling; enterprise platforms specialize in orchestration depth + governance (approvals/workspaces/SSO/data residency) + data infrastructure.

  - **Accounting ledgers vs spend layers:** QuickBooks, Xero, Sage Intacct are the actual double-entry GL/system-of-record; Ramp, Brex, Bill.com are spend/AP layers that sync into those ledgers and monetize via card interchange/cashback (cards & software often free) rather than seat licenses.

  - **Rewards ceilings:** Brex up to 7x category cashback and Bill.com/Divvy up to 7x, vs Ramp's flat ~1.5–5% savings-oriented model.

## Cross-category synthesis — what to build to compete

**The universal enterprise-software pattern (present in EVERY category above):**
1. **A visual, no-code builder** as the primary authoring surface (workflow/journey/dashboard/page/report canvas).
2. **A rules/automation engine** (trigger → condition → action) with a template library.
3. **An agentic AI layer** — every single vendor in every single category now ships (a) a conversational copilot, (b) generative authoring (NL → app/flow/email/report), and (c) autonomous multi-step **agents** with governance/guardrails. MCP + Google A2A are the emerging interop standards; most are LLM-agnostic/BYO-model.
4. **A unified data layer / semantic model** — CDP (marketing/analytics), Data Fabric (BPM/ServiceNow), Employee Graph (HR), semantic layer (BI), Customer 360 (CRM/commerce). "Define-once, use-everywhere" governed data is the strategic moat.
5. **A large pre-built integration marketplace + open REST/GraphQL APIs + webhooks** — connector counts (300–8,000+) are an explicit marketing axis.
6. **Enterprise governance baseline** — SAML SSO, SCIM, RBAC, audit logs, data residency, SOC 2 / ISO 27001 / GDPR / HIPAA.
7. **Tiered pricing (free/entry → pro → enterprise/custom)** with the AI/agentic/governance features gated to the top tiers.

**The generational shift every incumbent is racing toward:** from human-operated software → to **agent-operated software**. Outcome-based pricing (pay-per-resolution, Intercom Fin / Zendesk) is the leading edge of this in support; agentic commerce ("Commerce for Agents," Agentforce) and agentic finance (Ramp/Brex AI agents) are the same move in their categories. **A platform that is agent-native from the ground up — where the graph IS the app and agents author + operate it — leapfrogs the bolt-on-AI incumbents.** That is precisely the base-studio-code thesis.
